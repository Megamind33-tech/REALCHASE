# Studio Pack Assets

Export Babylon.js Editor packs into one directory per Asset Panel pack:

```text
public/scenes/apex/scene.babylon
public/scenes/horizon/scene.babylon
public/scenes/stadium/scene.babylon
public/scenes/talkline/scene.babylon
public/scenes/market/scene.babylon
public/scenes/prime/scene.babylon
```

Keep each pack's textures, environment files, and script-linked assets beside its
`scene.babylon` file, preserving the relative paths produced by the Editor export.
